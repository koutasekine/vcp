# spimats — 精度保証の手順と混合演算

この文書では、区間疎行列の policy `vcp::spimats<T, AP, DP>` の内部を説明します。

| 内容 | 場所 |
| --- | --- |
| 精度保証の手順(連立一次方程式・固有値・正定値性) | `vcp/spimats.hpp` |
| 区間行列と点行列の変換 | `vcp/spimats_base/spimats_convert.hpp` |
| 点と区間の混合演算 | `vcp/spimats_base/spimats_mixed_ops.hpp`(名前空間 `vcp::spimats_kernel`) |

利用者が直接呼ぶことは想定していません。使い方は [spmatrix.md](../spmatrix.md)
の「`spimats` の詳細」、policy の関係は [sparse_layers.md](sparse_layers.md)
を参照してください。

## 共通の規則

- **丸め**:`spimats.hpp` と `spimats_base/` は、丸めモードを自分で切り替え
  ません。方向付きの丸めが必要な計算は、すべて kv の区間演算(`mid`・
  `midrad`・四則)と `vcp::convert` に任せ、上界・下界は区間の端点
  (`.upper()`・`.lower()`)で取り出します。
- **近似と検証の分離**:近似の計算は、区間行列の中点を `AP`(既定は
  `vcp::spmats<T>`)で計算します。近似の結果は包含の成否と幅にだけ影響し、
  主張は区間演算による検証だけから得ます。近似の記録は `last_verify_info`
  に点の型のまま置き、保証の計算には流しません。
- **判定**:成功の判定は「確実に成り立つ」比較で行います。失敗側の判定は
  `!(x > c)` の形で書くので、NaN や ∞ は失敗側に落ちます。
- **失敗**:十分条件が成り立たなければ `vcp::verification_error` を投げます
  (`_with_info` の関数でも投げます)。このとき、対象の行列については何も
  主張しません。途中までの結果は返しません。
- **区間の比較**:区間が同じかどうかは、kv の `==`(確実に等しい)ではなく、
  端点のスカラー比較で判定します。

## 区間行列と点行列の変換

| 関数 | 動作 | 保証 |
| --- | --- | --- |
| `mid_for_approximation(IA, M)` | 各要素の `kv::mid` を M に入れる | なし。近似の入力専用 |
| `midrad_split(IA, M, R)` | 各要素に `kv::midrad` を使い、中点 M と半径 R に分ける | すべての A′ ∈ [IA] について、要素ごとに \|A′ − M\| ≤ R |
| `point_to_interval(A, IA)` | 各要素 a を点区間 [a, a] にする(丸めなし) | A ∈ [IA] |
| `identity_interval(n, IB)` | 対角が [1, 1] の単位行列を作る | [IB] = {I} |
| `convert_interval_matrix(IA, IB)` | 区間の型を変える(`vcp::convert` の外側丸め) | [IA] ⊆ [IB] |

ベクトル版もあります。保証に使う中点と半径は `midrad_split` で作ります。
`mid` と `rad` を別々に呼んで作ると、計算した中点の丸めの分だけ包含が
壊れるので使いません。値が厳密に零になった要素(中点が 0 の要素など)は
格納しません。

## 混合演算

名前空間 `vcp::spimats_kernel` の関数です。点の行列・ベクトルを区間の型に
写したコピーは作らず、スカラーの演算で kv の `interval<T> op T` の自動昇格に
任せます。結果が厳密に [0, 0] になった要素は格納しません。

| 関数 | 計算 | 主な用途 |
| --- | --- | --- |
| `mul_im_m` | 区間疎 × 点疎 → 区間疎 | shift の構成など |
| `mul_m_im` | 点疎 × 区間疎 → 区間疎 | R(A x̃ − b) など |
| `add_im_m`、`add_m_im` | 区間疎 + 点疎 → 区間疎 | A − cB など |
| `sub_im_m` | 区間疎 − 点疎 → 区間疎 | 点の側の符号を厳密に反転して `add_im_m` |
| `mul_im_v` | 区間疎行列 × 点ベクトル → 区間ベクトル | 残差 A x̃ |
| `mul_m_iv` | 点疎行列 × 区間ベクトル → 区間ベクトル | R の適用 |
| `mul_v_im` | 点の横ベクトル × 区間疎行列 → 区間の横ベクトル | RA − I を 1 行ずつ作る |

各要素は kv の区間演算だけで作るので、入力の区間の任意の点に対する真の
積・和を包含します。行列どうしの積と和は、作業量が `VCP_SPMATS_OMP_THRESHOLD`
以上なら、tsparse の並列版と同じ 2 段の方法で並列に作ります。結果は
スレッド数によらず逐次と一致します。この並列化は `VCP_SPMATS_NOMP`(または
`VCP_NOMP`)で止められます。

## 対称性の判定

`spimats` の `policy_is_symmetric`(tol なし)は、すべての (i, j) で A_ij と
A_ji の端点が一致するときだけ `true` を返します。固有値と `is_spd` は、
入力がこの意味で対称でなければ `vcp::domain_error` を投げます
(`is_spd` は `spd_options::nosymcheck` で検査を省けます)。

## 連立一次方程式

`solve` / `solve_with_info` / `lss`(`policy_lss_with_info_impl`)の手順です。

1. **近似**:[A] と [b] の中点 Ã、b̃ を作り、`AP` の LU 分解で P Ã Q = L U を
   1 回だけ求める。この因子から近似解 x̂ を解く(反復改良はしない)。
2. **行ごとの計算**:R ≈ Ã⁻¹ は作らず、第 i 行 R_i を因子から 1 行ずつ
   求める(Uᵀ・Lᵀ の三角行列の解法)。各行について、区間演算で
   - (R r)_i = R_i ([A] x̂ − [b])
   - G の第 i 行 = R_i [A] − e_iᵀ(`mul_v_im`、1 は厳密に引く)
   - (|G| e)_i = Σ_j |G_ij|
   を求める。G の行は保持せず、行和だけを残す(メモリは 1 行あたり O(n))。
3. **判定**:‖G‖∞ = max_i (|G| e)_i の上端が 1 未満と言えなければ
   `verification_error`。
4. **包含**:‖G‖∞ < 1 のとき A は正則で、真の解 x* について成分ごとに

   |x* − x̂| ≤ |R(b − A x̂)| + ‖R(A x̂ − b)‖∞ / (1 − ‖G‖∞) · (|G| e)

   が成り立つ。右辺を区間演算で評価して、x̂ ± 右辺を返す。

`lss_multi`(右辺が複数)は、LU 分解と R の行を右辺の間で共有します。

## 正定値性の判定 `is_spd`

`is_spd()` は、区間行列 [A] に含まれるすべての対称行列が正定値であることを
証明できたときに `true` を返します。`false` は「正定値でない」という主張では
なく、十分条件が成り立たなかったことを意味します。方法は Rump(1993, 1999,
2006)と INTLAB の `isspd` に基づきます。

1. **前処理**:`midrad_split` で [A] = ⟨M, R⟩ とする。対角の中点が正、
   対角の区間の最小の絶対値が正と言えなければ `false`。M の対角を [A] の
   対角の下端に置き換え、R の対角を 0 にする(下端に固定した行列が正定値
   なら、[A] の対称行列はすべて正定値)。
2. **尺度**:対角の最大と最小の比が √n より大きいとき、2 のべきの対角行列
   D による合同変換 D M D・D R D をかける(正定値性は変わらない)。各積が
   厳密に 2 のべき倍になることを確かめ、確かめられなければ尺度をかけない。
3. **並べ替え**:M と R に同じ対称な並べ替えをかける。
4. **半径の上界**:ρ(R) の上界 M_ρ を Collatz の上界
   ρ(R) ≤ max_i (Rx)_i / x_i で求める。
5. **近似**:点の `spmats<T>` で M の近似 Cholesky 分解を求め、逆反復で
   最小固有値の近似 t を求める。shift を s = M_ρ + 0.8 (t − M_ρ) とする。
6. **判定**:A_s = M − sI の近似 Cholesky 分解 L₂ を求め(失敗すれば s を
   小さくして再試行)、E ⊇ L₂ L₂ᵀ − A_s を区間演算で包含する。
   s − ‖E‖∞ > M_ρ と言えれば `true`。このとき、任意の対称な A′ ∈ [A] に
   ついて λ_min(A′) ≥ λ_min(M) − M_ρ ≥ s − ‖E‖∞ − M_ρ > 0。

点の行列(半径が零)も同じ中核で判定します(M_ρ = 0)。

## 固有値の包含

`eigs` / `eigs_with_info` と一般化の版(`policy_eigs_with_info_impl`、
`policy_generalized_eigs_with_info_impl`)は、対称な (A, B)(B は正定値)の
固有値の包含を返します。固有ベクトルは返しません。標準の問題は B = I と
して同じ手順で扱います(B が厳密に単位行列かどうかは、構造と端点で判定
します)。方法は、Yamamoto(2001)の LDLᵀ の慣性による分離と、
Lehmann–Behnke の精密化を、`veigs`(Liu–Yanagisawa)に沿って実装した
ものです。

1. **正規化**:A と B を 2 のべきで割る(結果は元の尺度に戻して返す)。
2. **近似**:中点の行列について、`AP` の `eigs` で近似固有値を求める。
   求める個数は、要求の個数より少し多めから始め、収束しなければ減らして
   試す。
3. **B の最小固有値の下界**:λ_B_min の下界を、`is_spd`(B − λI)の二分法で
   求める。
4. **分離**:近似固有値をクラスタに分け、クラスタの間に分離点 λ をとる。
   各 λ について、
   - `AP` の shift 付き LDLᵀ の handle で、中点の行列について
     A − λB ≈ P L D Lᵀ Pᵀ を求める([tsparse_ldl.md](tsparse_ldl.md))。
   - 残差 diff = P L D Lᵀ Pᵀ − ([A] − λ[B]) を区間演算で包含し、
     err = ‖diff‖∞ / λ_B_min の上界を求める。`is_spd`(err/2 · [B] ∓ diff)が
     通る間は err を半分にして締める。
   - D の慣性(区間で数え直す)から、λ − err と λ + err の間に固有値の番号の
     境目があることを確定する。err がクラスタの間の幅より大きければ失敗。
   両端は、`is_spd` の判定(すべての固有値がある値より大きい・小さい)で
   決めます。その結果、各クラスタについて「番号 N_c + 1 から N_{c+1} の
   固有値はすべて区間 [dn_c, up_{c+1}] に含まれる」が得られます。
5. **精密化**:各クラスタについて、区間の密行列 policy `DP` の `eigsymge`
   (一般化固有値の包含)で Lehmann–Behnke の精密化を行い、分離で得た区間との
   共通部分を返す。

返す包含の個数は、要求した個数より少ないことがあります。返した個数は結果の
`returned_count` に入ります(例:対角を幅 0.02 の区間にした n = 60 の 3 重対角
行列で k = 3 を求めると、包含は 1 個でした)。

`target` が `smallest_algebraic` / `largest_algebraic` のときは、返すクラスタが
端であることを慣性で証明します(できなければ Rayleigh 商による退路を使い
ます)。それ以外の `target` では、返した固有値の番号を `last_verify_info` の
`veigs_index_lo` / `veigs_index_hi` に記録し、要求した順位(最も近い・最も
大きい)であることの検査を `spi_opt.target_rank_check` で選びます。

| `target_rank_check` | 動作 |
| --- | --- |
| `off` | 検査しない |
| `record`(既定) | 検査して `veigs_rank_certified` に記録する(1 = 証明できた、−1 = できなかった)。返す結果は変えない |
| `require` | 証明できなければ `verification_error` |

## 計算の記録

`last_verify_info`(`spimats_verify_info<T>`)には、近似の結果
(`ap_lss_result`、`ap_eigenvalues`、`spimats_options::keep_ap_eigenvectors`
のときは近似固有ベクトル)と、検証の進み具合(`stage`、‖G‖∞ の上界、
`is_spd` の shift や反復回数、分離の二分法の回数、クラスタの数など)が
入ります。これは計算の記録であり、対象の行列についての主張ではありません。
`verification_error` が投げられた後も、policy のオブジェクトから読めます。
